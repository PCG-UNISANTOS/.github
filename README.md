# Organização Achados e Perdidos – UNISANTOS

Bem-vindo ao perfil da organização **Achados e Perdidos – UNISANTOS**!  
Este espaço reúne toda a documentação e implementação do sistema acadêmico de **Achados e Perdidos**, desenvolvido por alunos da **Universidade Católica de Santos (UNISANTOS)**.

## Objetivo

O projeto tem como objetivo:
- Facilitar a **localização de itens perdidos** dentro do ambiente acadêmico.  
- Permitir que **alunos** busquem e solicitem a retirada de itens encontrados.  
- Garantir que **administradores** possam cadastrar, atualizar e validar informações de itens.  
- Documentar e implementar o sistema utilizando **boas práticas** aprendidas durante a vida acadêmica.

## Tecnologias Utilizadas

- **Frontend:** Aplicação Web  
- **Backend:** API .NET 9  
- **Banco de Dados:** PostgreSQL  
- **ORM:** Entity Framework  
- **Infraestrutura:** Docker, GitHub, Render  
- **Serviços adicionais:** Cloudflare R2, Serviço de E-mail, Swagger/Postman
